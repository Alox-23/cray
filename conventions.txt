Create ExampleSubsystem:
  Function desc:

    ·returns a pointer to ExampleSubsystem
  Failier:

Destoy ExampleSubsystem:

Static Functions:
 ·All functions that are not called by anothyer subsystem outside of the file, should be static and farward declared at the top of the source file
